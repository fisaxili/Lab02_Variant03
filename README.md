##  Описание проекта

Данный проект представляет собой десктопное приложение на Windows Forms (C#), разработанное для решения трех задач согласно варианту №3. Приложение имеет удобный интерфейс с вкладками и демонстрирует работу с условными операторами, циклами и графической визуализацией.

### Основные функциональные возможности:

#### **Задача 1: Конвертер температур** 🌡️

*   Двусторонняя конвертация между шкалами Цельсия и Фаренгейта
*   Автоматический пересчет при вводе значения в любое поле (события TextChanged)
*   Защита от некорректного ввода и обработка исключений
*   **Формулы перевода:**
    *   `°F = °C × 9/5 + 32`
    *   `°C = (°F - 32) × 5/9`

#### **Задача 2: Генератор чисел Фибоначчи** 🔢

*   Генерация первых N чисел последовательности Фибоначчи
*   Визуализация последовательности в ListBox
*   **Математическая модель:** `F₁ = 1, F₂ = 1, Fₙ = Fₙ₋₁ + Fₙ₋₂`

#### **Задача 3: Визуализация треугольника** 🔺

*   Проверка существования треугольника по трем сторонам
*   Определение типа треугольника: равносторонний, равнобедренный, разносторонний
*   Графическая отрисовка треугольника в PictureBox с автоматическим масштабированием
*   Вычисление дополнительных параметров (периметр, площадь, углы)
*   **Условие существования:** `a + b > c`, `a + c > b`, `b + c > a`
